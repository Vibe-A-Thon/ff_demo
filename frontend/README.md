# Fraud Forge Frontend

React UI for the Fraud Forge demo. Uses CRA with CRACO and Tailwind.

## Scripts
- `yarn start` / `npm run start`: Run the dev server.
- `yarn test` / `npm run test`: Run frontend tests.
- `yarn build` / `npm run build`: Build production assets.

## Environment
- `REACT_APP_BACKEND_URL`: Backend base URL (used by API client).

## Structure
- frontend/src: App entry, screens, components, and API clients.
- frontend/public: Static assets.

For full system setup, see the root [README.md](../README.md).
